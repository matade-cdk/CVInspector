# Assets Folder

## Add Your Logo

Place your **logo.png** file in this folder to display it on the website.

### Steps:
1. Copy your logo.png file
2. Paste it here: `frontend/src/assets/logo.png`
3. Also copy the logo to: `frontend/public/favicon.png` (for favicon)

The logo will automatically appear in the header and as the browser favicon!

### Recommended Logo Size:
- **Header Logo**: 120x120px (or any square image)
- **Favicon**: 32x32px or 64x64px
